# JN Gonzales

Full-stack developer in Imus, Cavite, Philippines (GMT+8). I take over live Next.js, Shopify and Python systems, finish them, and hand them over documented.

**Open to work** — freelance and contract, async by default, replies within hours on weekdays.

## What I do

- **Rescue and finish.** Inherit a half-built or broken product, ship the remaining scope, leave a written handover instead of a "good luck".
- **Shopify.** Apps and storefront work: OAuth, Polaris admin UI, webhooks, bulk backfill, billing, GDPR endpoints.
- **Automation.** Scraping and enrichment pipelines, browser automation with Playwright, API and CRM glue.

## Selected work

- [**kitstock**](https://github.com/jngonzales/kitstock) — Shopify app for bill-of-materials and bundle stock: tracks component inventory and reserves it when a bundle sells.
- [**Tagmatic**](https://github.com/jngonzales/Tagmatic) — production Shopify app. Rule engine for automatic order tagging, webhook processing, bulk backfill, billing and GDPR.
- [**Real-Estate-Deal-Platform**](https://github.com/jngonzales/Real-Estate-Deal-Platform) — property deal scoring platform, live at [real-estate-deal-platform.vercel.app](https://real-estate-deal-platform.vercel.app).
- [**property-research-engine**](https://github.com/jngonzales/property-research-engine) — FastAPI, PostgreSQL and Redis pipeline that scrapes and enriches listings, orchestrated with n8n.
